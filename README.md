# Uber Sales Dashboard using Power BI and AI

![Uber Dashboard](./Images/uber%20dashboard.png)

## Project Overview

This project is based on analysing Uber sales and ride data using Power BI.  
The goal was to convert raw operational data into clear business insights which can help in better decision making.

The dashboard focuses on ride performance, revenue trends, customer behavior, booking patterns and location level demand.

Along with traditional dashboarding, some AI based visuals and smart insights were also used to identify trends faster.

---

## Problem Statement

Transport businesses like Uber generate huge amount of daily ride data.  
But raw data alone does not help management.

They need answers like:

- Which locations generate highest revenue?
- What time bookings are highest?
- Which days are weak in performance?
- How customer demand changes over time?
- Which areas need more drivers?
- What are cancellation trends?

This dashboard was created to solve such business questions.
